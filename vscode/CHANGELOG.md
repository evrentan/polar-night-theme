## [1.0.0] - 2026-09-11

### Added

- Initial release of Polar Night theme
- Deep navy background (`#0d1b2e`) optimized for long coding sessions
- Rich but muted color palette: sage green, soft amber, lavender, pale blue
- Full UI chrome coverage: activity bar, sidebar, tabs, status bar, terminal, minimap, panels
- Comprehensive syntax token coverage: JS/TS, Python, Java/Kotlin, Rust, Go, CSS/SCSS, HTML/JSX, JSON/YAML, Markdown, Shell
- Semantic highlighting support
- Italic comments for visual hierarchy
- Bracket pair colorization
