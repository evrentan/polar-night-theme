# Polar Night — JetBrains Theme

[![CI](https://github.com/evrentan/polar-night-theme/actions/workflows/ci.yml/badge.svg)](https://github.com/evrentan/polar-night-theme/actions/workflows/ci.yml)

A deep navy dark theme with rich but muted syntax colors, designed for focused, distraction-free coding sessions.

Compatible with all JetBrains IDEs: IntelliJ IDEA, WebStorm, PyCharm, GoLand, Rider, CLion, DataGrip, and more.

## Installation

### Via JetBrains Marketplace

1. Open **Settings** (`Ctrl+Alt+S` / `Cmd+,`)
2. Go to **Plugins** → **Marketplace**
3. Search for **Polar Night**
4. Click **Install** and restart the IDE
5. Go to **Settings** → **Appearance & Behavior** → **Appearance** → set **Theme** to **Polar Night**

### Via Disk (manual)

1. Download the `.zip` from [releases](https://github.com/evrentan/polar-night-theme/releases)
2. Open **Settings** → **Plugins** → gear icon → **Install Plugin from Disk**
3. Select the downloaded `.zip` and restart

## Design Choices

- **Deep navy background** — easier on the eyes than pure black for long sessions
- **Muted, desaturated syntax colors** — enough variety to distinguish tokens without visual noise
- **Italic comments** — visually separate from code without being distracting
- **Full UI coverage** — editor, tool windows, terminal, VCS log, diff view, debugger, notifications
