## [1.0.0] - 2026-09-11

### Added

- Initial release of Polar Night theme for JetBrains IDEs
- Deep navy background (`#0d1b2e`) optimized for long coding sessions
- Rich but muted color palette: sage green, soft amber, lavender, pale blue
- Full UI coverage: editor, tool windows, tabs, status bar, terminal, VCS log, diff view, debugger, notifications
- Comprehensive editor color scheme covering Java, Kotlin, Python, JS/TS, Go, Rust, CSS, HTML, XML, JSON, YAML, Markdown, Shell
- Italic comments for visual hierarchy
- Compatible with IntelliJ IDEA, WebStorm, PyCharm, GoLand, Rider, CLion, DataGrip (2024.1+)
